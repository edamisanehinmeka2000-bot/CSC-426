**Calculator and Login Page Project**

This repository contains two front-end web development projects built to practice and demonstrate fundamental HTML, CSS, and JavaScript skills.
Projects Included

**1. Calculator**

A simple calculator application that performs basic arithmetic operations such as:
Addition
Subtraction
Multiplication
Division
Clear/Delete functionality

**2. Login Page**

A responsive login interface designed with modern UI principles. Features include:
Username/Email input
Password input
Form validation
Responsive design
Technologies Used
HTML5
CSS3
JavaScript
